# CSE3120_project
CSE3120 Contest 1 project

Flappy Bird Clone in MASM

A text mode Flappy Bird clone written in 32-bit x86 assembly 
Team: Grady Degyansky, Ryan Giacoboni

How to Play:
Space (home screen)	Start a game
Space (in game)	Jump
Q (home screen)	Quit
Esc (in game)	End the current game
Enter (game over screen)	Return to the home screen

Fly the bird (>) through the gaps in the towers (#). You score one point for every tower you pass. Hitting a tower, the ground (=), or the top of the screen ends the game.
